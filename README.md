🚀 AI Interview Platform

A full-stack AI Interview Preparation Platform built using the MERN stack. This project enables users to register, log in securely, and access an interactive dashboard. It demonstrates authentication, API integration, and full-stack development workflow.


//📌 Features

- 🔐 User Registration & Login
- 🛡️ JWT-based Authentication
- 🌐 RESTful API integration
- 🗄️ MongoDB Atlas cloud database
- ⚡ Frontend built with Next.js
- 🔄 Backend built with Node.js & Express.js
- 📡 Axios for API communication
- 📦 Modular project structure (Client + Server)
